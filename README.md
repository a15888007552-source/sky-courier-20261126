Sky Courier — Alpine Run: a complete, original flight game that plays offline in a desktop browser from static files. Chase view over a procedural alpine valley, a prop courier in frame with lit instruments, glowing rings to fly through, and a runway to land on. Three missions (Valley Run, Alpine Pass, Night Courier), fuel and throttle discipline, and a full HUD: airspeed, altitude, heading, attitude, throttle and fuel.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Arrow keys bank and pitch, Shift feeds the throttle, Ctrl pulls it back, P pauses. Mouse: drag to steer, hold for throttle. 1 / 2 / 3 chooses a mission; Space starts.

## Hand it in

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
